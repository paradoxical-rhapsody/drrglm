# drrglm


## Installation

1. From CRAN:
    ```R
    install.packages("drrglm")
    ```

2. From github ([RTools](https://cran.r-project.org/bin/windows/Rtools/) is requires on Windows platform to compile the source code):
    ```R
    library(remotes)
    install_github("paradoxical-rhapsody/drrglm")
    ```


## Usage

For detailed information on the usage and examples in the package, please refer to the documentation:
```R
help(, drrglm)
```


## Reference

Zengchao Xu, Shan Luo, and Binyan Jiang. "Doubly Regularized Matrix-Variate Regression". Journal of Computational and Graphical Statistics. <doi:10.1080/10618600.2026.2702534>
